# ระบบบทเรียนคอมพิวเตอร์ช่วยสอนผ่านเว็บ วิชาวิทยาการคำนวณ ป.5 (ระบบ AR)

แพลตฟอร์มการศึกษาดิจิทัล (Web-based Courseware & LMS) นี้ได้รับการพัฒนาขึ้นเฉพาะกิจสำหรับหลักสูตร **วิชาวิทยาการคำนวณ (รหัสวิชา 11226767)** ระดับประถมศึกษาปีที่ 5 ของโรงเรียนจากัวร์วิทยาคม โดยเน้นการสร้างประสบการณ์ผู้เรียนผ่านเทคโนโลยีเสมือนจริง (Augmented Reality - AR) ที่ผสานการปฏิสัมพันธ์แบบเรียลไทม์

โครงสร้างระบบออกแบบมาให้เป็นสถาปัตยกรรมคลาวด์แบบเบาบาง ใช้สคริปต์หน้าเว็บเดี่ยวทำงานร่วมกับฐานข้อมูลแบ็กเอนด์ทรงประสิทธิภาพอย่าง **Supabase**

---

## 💡 จุดเด่นและฟังก์ชันการทำงานหลัก

### ฝั่งนักเรียน (Student Module)
- **ระบบยืนยันตัวตนจำกัดสิทธิ์:** ลงทะเบียนใช้งานเฉพาะบัญชีที่ตรงกับรหัสนักเรียน 11 หลักในฐานข้อมูลกลางเท่านั้น
- **หน้าจัดการโปรไฟล์:** รองรับการอัปโหลดรูปภาพประจำตัวพร้อมระบบลดขนาดไฟล์อัติโนมัติ
- **ชุดแบบทดสอบวัดผลสัมฤทธิ์ (Pre-test / Post-test):**
  - ข้อสอบแบบสุ่มชุดคำถามตามรูปแบบเลขรหัสประจำตัวนักเรียน
  - ระบบประมวลผลคะแนนทันที พร้อมเฉลยคำตอบในแบบทดสอบหลังเรียน
- **บทเรียนอัจฉริยะ 5 หน่วยการเรียนรู้:**
  - ครอบคลุมตั้งแต่พื้นฐานแนวคิด AR, ประเภทสื่อ, วิธีออกแบบโมเดล 3 มิติ, การใช้งานระบบ WebAR จนถึงขั้นตอนตรวจสอบผลงาน
  - บันทึกสถานะการเรียนรู้อัตโนมัติเมื่อศึกษาจบแต่ละหัวข้อ
- **ห้องปฏิบัติการ WebAR & การส่งงาน:**
  - แสดงผลโมเดลสามมิติผ่านคอมโพเนนต์ `<model-viewer>` ในเบราว์เซอร์ได้ทันที
  - ส่งลิงก์ผลงานภายนอก หรืออัปโหลดไฟล์มัลติมีเดีย (วิดีโอ/ภาพถ่าย)
- **คลังแหล่งเรียนรู้:** ดาวน์โหลดเอกสารประกอบ หรือเข้าชมวิดีโอการสอนที่ผู้สอนจัดเตรียมไว้

### ฝั่งผู้สอน (Instructor Dashboard)
- **ระบบตรวจสอบภาพรวมชั้นเรียน:**
  - ตรวจสอบสถานะการเข้าเรียนและความก้าวหน้าของนักเรียนรายบุคคล
  - ติดตามผลคะแนนทดสอบก่อนและหลังเรียน
  - **การคำนวณ Normalized Gain ($g$) แบบอัตโนมัติ** เพื่อวิเคราะห์สัมฤทธิผลทางการเรียน
  - ส่งออกรายงานผลการเรียนเป็นไฟล์ตารางข้อมูล (CSV)
- **ระบบตรวจให้คะแนนงานปฏิบัติ:** ตรวจสอบไฟล์ผลงานหรือลิงก์ของนักเรียน พร้อมบันทึกคะแนน (0-100) และข้อเสนอแนะเชิงพัฒนาการ
- **ศูนย์จัดการเนื้อหา:** เพิ่ม ลบ หรือแก้ไขสื่อการเรียนรู้ ทั้งไฟล์เอกสาร (PDF, PPTX) และลิงก์วิดีโอภายนอก

## ⚙️ สถาปัตยกรรมและเทคโนโลยีระบบ

- **Frontend Interface:** 
  - สร้างด้วย HTML5 / CSS3 / Vanilla JavaScript 
  - ตกแต่งหน้าตาด้วย Tailwind CSS ผ่าน CDN
  - รองรับการแสดงผล 3D Model ด้วย Google Model Viewer
- **Backend & Cloud Services (Supabase):**
  - **Supabase Auth:** ระบบจัดการผู้ใช้งานและความปลอดภัย
  - **PostgreSQL Database:** จัดเก็บตารางข้อมูลหลักและตรรกะฐานข้อมูล
  - **Supabase Storage:** จัดเก็บไฟล์รูปภาพ โปรไฟล์ และสื่อการเรียนการสอน
  - **Row Level Security (RLS):** กำหนดสิทธิ์การเข้าถึงข้อมูลระดับคอลัมน์/แถวอย่างเข้มงวด

## 📋 ขั้นตอนการติดตั้งระบบ

### 1. การเตรียมโครงสร้างฐานข้อมูลบน Supabase
1. เข้าสู่ระบบแดชบอร์ด Supabase ของท่าน
2. ไปที่เมนู **SQL Editor**
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `supabase_setup_script.sql` ไปวาง และกดปุ่ม **Run**

### 2. การกำหนดค่าเชื่อมต่อในระบบส่วนหน้า
1. เปิดไฟล์ HTML หลักของระบบ
2. ค้นหาค่ากำหนดการเชื่อมต่อ API:
   ```javascript
   const SUPABASE_URL = "YOUR_SUPABASE_URL";
   const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
   ```
3. นำ URL และ Public Anon Key จากหน้า Project Settings -> API ของ Supabase มาใส่ให้ถูกต้อง

### 3. การสร้างบัญชีผู้สอนและตั้งค่าสิทธิ์
1. สร้างบัญชีผู้ใช้งานใหม่ผ่าน Supabase Dashboard -> Authentication -> Add User
2. ไปที่ **SQL Editor** แล้วรันคำสั่งให้สิทธิ์บัญชีนั้นเป็นผู้สอน:
   ```sql
   INSERT INTO public.teachers (user_id)
   SELECT id FROM auth.users WHERE email = 'อีเมลผู้สอนของคุณ@domain.com';
   ```
